## 绿色描线对应的固定锚点

| 编号 | 锁定部位 | 固定内容 |
|---|---|---|
| S1 | 冠壳整体外缘 | 冠顶长低轮廓、前端伸出与转折、后脑弧形回落，整体长度高度及各段相对位置固定；不得改高拱圆顶 |
| S2 | 后脑小台阶／压片 | 凸脊后方可见的短层叠构件，保留数量关系、位置和小尺度体量；不能删除、加大或换成尾翼 |
| S3 | 顶部短凸脊 | 局部抬升、顶面、陡边和短回落肩固定；不能改成外挂盒、按钮或长鳍，也不能融入冠面消失 |
| S4 | 下延夹接带 | 从短凸脊到耳位的两条侧边、带宽及转折固定，夹住冠壳和面罩；下端被耳罩遮住。不得增加额头中央宽压条 |
| S5 | 冠壳下沿与面罩交界 | 横向交界、耳区让位和前端下落边固定；不新增封边框轨，保留指定局部微小前后间距 |
| S6 | 面罩／后包覆面外缘 | 绿线划定的连续包覆轮廓、弧度、下缘斜收及耳位关系固定；不能换成另一块长盾牌或缩窄覆盖 |
| S7 | 耳罩及相邻小连接件 | 圆角方形外轮廓、外框厚度、面板包络、旁边窄连接块的位置和数量关系固定；耳罩外包夹接带，不扩大或重新造型 |
| S8 | 下巴承托片 | 图中独立倾斜的大承托片边界、斜向上缘、下缘弧度和连接处固定；保留原图的大面与前兜姿态，不另造厚下巴块 |
| S9 | 耳下支撑与下方斜线 | 从耳区向下巴及颈部过渡的斜向分界、内侧负空间和遮挡固定；不能画任意装饰斜线代替 |
| S10 | 短颈 | 前后两侧轮廓、内收转折、前缘细边及斜向底缘固定；完整呈现，不截断、不加肩部和底座 |

**全部外轮廓、主分件线、相对比例、连接点和遮挡都是锁定信息。** 即使仍能识别为同类头盔，改变以上任一结构也不是当前允许的皮肤变化。内凹、浮雕、凹槽、接口如会改变结构线、投影或明暗体块，也不得自行增加。

## 验收：结构先于皮肤

1. 对照绿色描线图，S1—S10逐项核对：外轮廓、分件线、连接位置及遮挡一致。
2. 遮去配色图案后，仍是同一个基底；颜色不能掩饰几何改变。
3. 短凸脊清楚存在、下延夹接正确且耳罩外包；无额头宽压条、无面罩独立封边。
4. 微间距是自然前后错位，不是挖缺口、宽槽或额外框轨。
5. 下巴、负空间和短颈完整，斜向底缘与结构基准一致。
6. 延伸皮肤主题、图形和材质清楚；不把原皮0/2、迷彩和刮痕原样复制当作新设计。
7. 实际画布尺寸、模板右栏和主体居中符合规范，辅助线一律不出现。

**任何固定结构被改动，或任一强制比例不符合，一律不通过，不作为结果展示；继续内部修正。** 未核验标待核验，不称通过。若工具自动展示未经核验的结果，不得假称已经实现预审拦截。创作者明确批准最终前不登记成品。
